# 红果鉴 / 真果鉴

## 项目背景

基于鱼佬原「短剧库 APP」源码持续维护的 Flutter 多端短剧 / 影视应用。本仓库用于学习与个人维护，支持浏览、搜索、在线播放、追剧记录和下载。

站源请求、解析、播放和下载在设备端完成，不依赖自建后台服务。站源可用性取决于源站及网络，应用不解除 VIP 或其他授权限制。

当前源码版本：**0.2.88+95，开发快照**，尚未完成集中验证与真机验收。

## 使用说明

### 获取安装包

安装包发布后，可在 [Releases](https://github.com/KKKKKKKEM/guoapp/releases) 下载；尚未发布时，可在 [Actions](https://github.com/KKKKKKKEM/guoapp/actions) 查看构建进度。

| 版本 | 站源范围 |
| --- | --- |
| 红果鉴 `hongguojian` | 仅红果 |
| 真果鉴 `zhenguojian` | 红果、韩小圈、鬼片、青空等全部 11 个站源 |

Android 手机、电视和盒子使用同一套 APK，按设备架构选择：

- `arm64-v8a`：大多数 Android 手机、电视和盒子。
- `armeabi-v7a`：32 位 Android 系统。
- `x86_64`：对应设备或模拟器。

两版使用相同应用标识，不能作为两个独立应用并排安装；覆盖升级要求签名一致。标注为预览版的 APK 使用 debug 签名，不能保证覆盖旧安装包。需要卸载旧版时，先在应用内备份个人记录。

### 基本操作

1. **浏览与搜索**：在首页 / 发现页选择站源和分类，使用搜索、排序或筛选查找内容。部分站源支持在线搜索，部分仅筛选已加载的剧库。
2. **播放与选集**：点击剧目进入播放，在选集面板切换分集；获取信息失败时可重试。播放器提供画质、倍速及播放设置。
3. **追剧与续播**：通过卡片「更多」或详情页添加追剧，在「最近观看」继续上次播放；记录按用户独立保存。
4. **下载与本地播放**：在播放页或详情页的下载入口选择分集和画质，在下载页暂停、继续、重试或播放已下载内容。
5. **站源与设置**：从更多 / 设置进入站源管理、用户管理、网络与资源、备份及设备互联。真果鉴的部分站源默认隐藏，需要在站源管理中解锁；受限用户还需管理员授权。

**手机**：普通模式支持左右区域调节亮度 / 音量、横向拖动调整进度；短剧模式支持上下滑动换集。可在播放设置中切换模式和方向，长按画面临时倍速。

**电视 / 盒子**：使用方向键移动焦点，确认键进入或播放，长按确认 / 菜单键打开更多操作；返回键逐级关闭面板或退出当前页面。
